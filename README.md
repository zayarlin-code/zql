## ⚙ Installation

```bash
git clone https://github.com/zayarlin-code/zql
cd zql
python3 zql.py
```

---

## 🚀 Usage

### Interactive Mode

```bash
python3 zql.py
```

### Full Scan

```bash
python3 zql.py scan http://target.com?id=1
```

### WAF Detection

```bash
python3 zql.py waf-detect https://target.com
```
